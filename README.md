# Kitty Space Adventure

## Project Option
Simple Browser Game

## Project Description
Kitty Space Adventure is a space themed browser game where players choose one of four astronaut cats and travel through space collecting stars while avoiding dangerous asteroids and black holes. The objective is to collect enough stars before the timer runs out while keeping the cat's health above zero. The game includes a title screen, character selection, mission briefing, gameplay, victory screen, and game over screen, creating a complete interactive experience from start to finish.

## Theme Interpretation
My project responds to the theme of Space by placing players in an outer space environment where they control an astronaut cat exploring the galaxy. Players must navigate through floating space hazards while collecting stars, creating a playful interpretation of a space adventure. The backgrounds, characters, icons, and gameplay all reinforce the overall space theme.

## Intended User or Player
This game is designed for casual players of all ages who enjoy simple arcade style games. It is especially intended for users looking for a fun and lighthearted experience that is easy to learn.

## User or Player Goal
The player's goal is to collect 15 stars before the timer reaches zero while avoiding asteroids and black holes. Successfully collecting enough stars wins the game, while running out of health or time results in a game over.

## Main Features
- Title screen with game introduction
- Character selection with four astronaut cats
- Mission briefing before gameplay
- Keyboard controls (WASD and Arrow Keys)
- Mobile on screen controls
- Collectible stars that increase the score
- Asteroids and black holes that damage the player
- Health, timer, and score tracking
- Win and Game Over screens
- Restart functionality

## JavaScript Features
JavaScript controls all of the game's interactive systems, including:
- Character selection
- Screen transitions
- Player movement
- Random spawning of stars and hazards
- Collision detection
- Score tracking
- Timer countdown
- Health system
- Win and lose conditions
- Restarting the game
- Mobile button controls

## Responsive Design
The game adapts to different screen sizes using CSS media queries. On smaller screens, the layout stacks vertically to improve readability, and mobile control buttons appear so the game can be played without a keyboard. Buttons and interface elements remain accessible across different screen sizes.

## User Testing
I conducted user testing with classmates who played the game on different screen sizes and tested multiple characters. Overall, players found the instructions, controls, and gameplay easy to understand. The responsive layout and mobile controls also worked well. The main feedback was that the mission instructions did not match the updated gameplay values and that the collision area around the player felt too large, causing damage even when objects did not appear to touch the cat.

## Revisions
After user testing, I made several meaningful improvements:
- Updated the mission instructions so they accurately reflect the game's health and damage values.
- Improved the collision detection by reducing the player's collision area, making gameplay feel fairer.
- Continued balancing the gameplay by adjusting hazard behavior and overall difficulty while maintaining an enjoyable experience.
